# 📝 Gestor de Tareas - To Do App (Python + Tkinter)

Aplicación de escritorio simple para gestionar tareas desarrollada en **Python** usando **Tkinter**.

Permite agregar, completar y eliminar tareas, guardando la información en un archivo JSON para que no se pierdan al cerrar el programa.

---

## 🚀 Características

- ✅ Agregar tareas
- ✔ Marcar / desmarcar tareas como completadas
- 🗑 Eliminar tareas
- 💾 Guardado automático en archivo `tareas.json`
- 📊 Contador de tareas pendientes
- 🎨 Interfaz con estilos personalizados
- 🖱 Doble click para completar tarea

---

## 🛠 Tecnologías utilizadas

- Python 3
- Tkinter
- ttk (Themed Tkinter Widgets)
- JSON
- Manejo de archivos
